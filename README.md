## How I Build

**01 — Start with a real problem**  
I look for workflows that break down in the field: scattered survey notes, missed leads, hidden deadlines, difficult handoffs, or repetitive service processes.

**02 — Map the workflow**  
I define the users, steps, decisions, data, integrations, and handoffs before shaping the interface.

**03 — Build with AI**  
I use AI as part of the engineering workflow — not just as a chatbot. Claude, ChatGPT, Gemini, Claude Code, APIs, speech-to-text, and voice agents help me design, build, test, and refine applications.

**04 — Ship and improve**  
I deploy working applications, test real workflows, identify friction, and iterate.
